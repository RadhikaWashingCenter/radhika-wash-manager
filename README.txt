Radhika Wash Manager v3.3.12 — No Registration Number / Permanent Vehicle ID

INSTALL / UPGRADE
1. In the EXISTING Live app, export Settings > Full JSON Backup and keep it safe.
2. Extract this ZIP and replace files in the SAME GitHub Pages repository/path.
3. Commit changes and reopen the SAME URL. Do NOT clear Chrome Site Data.
4. In Test Mode, try New Wash > No Registration Number and save a sample.

FEATURES
- Tick No Registration Number / Not Available on New Wash Entry.
- First time: auto-generated Vehicle ID such as RWC-V0001 (allocated at Save).
- Returning vehicle: search by Vehicle ID, type, name, mobile or description, then select existing ID.
- Permanent Vehicle ID is independent of Receipt Number; each new wash gets a new receipt.
- Registry is included in the existing Full JSON / Google Drive business state.
- Old records and receipt counters use the same original Live storage keys (not overwritten).
- Registered cars still use their actual plate numbers; custom vehicle incentives unchanged.
- Manual attendance unchanged; no Wash Stage selector on New Wash Entry.

CAUTION
Test mode is an independent database. Never restore a TEST backup into Live Mode.
Local phone/Android and Google Drive OAuth flow should be checked on your actual device.
When an old record has a fleet ID instead of a plate, do not assume it is an RWC-V ID without checking.
