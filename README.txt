Radhika Wash Manager v3.3.20 — Per-entry Car Incentive Slab Count

On New Wash, for Other Service or Custom Vehicle select Yes or No (default No). Yes consumes one immutable daily car slab position, while its worker incentive still follows its independent rate. View status in Wash Records; edit it via Edit. Existing earned or paid incentives are not recalculated.

INSTALL: Back up Live Mode JSON, extract this ZIP, upload index.html, sw.js, manifest.webmanifest, icon-192.png and icon-512.png to your existing GitHub Pages repository root. Refresh online. Do not clear browser/site data. Test Mode is separate from Live Mode. Google Drive sync and Android installation require device-side validation.
